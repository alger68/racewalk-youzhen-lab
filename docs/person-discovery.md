# 人物候選去重與驗證

不同裁切中的頭肩、髖中心與尺度須一致才合併完整骨架；以群組內兩兩相容避免連鎖誤合併。同一辨識批次分開出現的結果不合併。物件框僅在唯一相容骨架存在時加入群組，不由外框推造關節。

尚未確認頭肩或只有單次骨架的區域，自動用較集中的裁切再辨識一次（最多 12 個區域，整體保留 60 秒期限）。再次辨識仍保留同框其他候選，不強制指定影片人數。待確認區域可展開選取，未確認不代表不存在人物。

## 與接觸分析的區別

此版本修改選人前的候選發現，持續追蹤與每側量測守門維持原有方式。高信心度不代表身分正確；遮擋或身分未確認仍不取值。接觸使用已確認地面設定，不以全段腳部高度百分位自動代替地面。缺口不以線性內插產生角度或接觸事件。
