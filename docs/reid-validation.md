# 2.9.0 人物外觀輔助追蹤

## 做了什麼

在 Full＋RTMPose 觀測流程後，新增 YOLO26n-ReID 512 維外觀特徵。保留所有已偵測人物的短期軀幹位置、速度及外觀記憶；互為唯一且有足夠差距的匹配才能指派人物。模型輸出順序不是身分。同時保留暫時消失的競爭人物，避免只剩一個框就自動認定是目標。

不清楚的觀測不更新外觀記憶；重新取得目標需三格獨立觀測與軀幹核對。記憶最多三秒、64 個短期紀錄；超時不把新人物接回原身分，繼續掃描並提示重新圈選。位置預測只用於匹配，不產生關節、角度或接触資料。

身分匹配與左右腿品質仍是兩道獨立檢查，原有 RTMPose／點位／連續性守門保留。初始人物候選偵測仍為 MediaPipe＋EfficientDet；沒有硬設四人，也不能宣稱這次已解決所有漏抓與重複框。
