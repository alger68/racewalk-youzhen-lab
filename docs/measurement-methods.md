# 量測數學與驗證邊界（2.7）

本版保留 MediaPipe Full＋RTMPose 的身分與點位檢查。新數學只處理已取得的觀測；不修補遮擋、不替換骨架、不自動確認裁判結果。前端、報告與匯出均保留方法及假設。

## 接觸候選：hmm-ground-v1

啟用條件：側面、已圈選目標、有效地面線、使用者確認固定鏡頭／整段地面線適用、鞋底清楚、時間設定確認。每幀另外需要同一目標身分鎖定、精確時間、可用腳跟與腳尖、可用人體尺度。任何缺失都留在時間軸，不進入時序推論。

地面點按 x 排序，換回原片像素。對地面向量 (dx,dy)，點 p 的帶符號垂直距離：

`d(p) = [dy × (px-ax) − dx × (py-ay)] / hypot(dx,dy)`

正值在地面上方。這處理原片寬高比例、斜線與端點反轉，仍只是二維地面參考，不是三維鞋底間隙。

尺度 L 為可信左右肩到髖像素距離的平均，L < 25 px 不取值。暫定近地面帶 r = 0.08 L；任一足部點低於地面超過 1.5r 時資料無效。任一足部點距地面絕對值 ≤ r 是近地面觀測；兩點皆高於 2r 是清楚的高於地面觀測。這些是未校準的工程參數，不是接觸真值或競走判罰門檻。

以兩點最低高度 h = min(dheel,dtoe) 建立空間支持：

`e_space = clamp(exp(−0.5 × (h/r)²), 1e−5, 1−1e−5)`

連續有效觀測以實際時間 `(file_time / slow)` 求高度差分，將 `abs(dh/dt) / r` 作為相對地面法向速度。較大的法向速度會降低近地面支持，乘上 `0.55 + 0.45 × exp(−0.5 × (speed/12)²)`。這是啟發式觀測模型，不是從競走標籤擬合的似然。

每側各自執行二狀態 HMM forward/backward。初始先驗各 0.5；每次轉移 `q = (1−exp(−8Δt))/2`，對稱、允許每一格切換。沒有左右交替硬限制、沒有最短離地持續時間、沒有「一定要正常走路」的路徑。

- 近地面觀測需 posterior ≥ 0.9，且相鄰連續幀也有近地面觀測，才顯示綠色。
- 清楚的高於地面觀測即使只有一格也保留棕色，不被 HMM 平滑抹去。它只提出人工複查候選。
- 高度邊界、鞋底缺值與身分缺口保留未知。缺口、時間不遞增、超過預期取樣間隔 1.8 倍、continuity 改變都切斷時序。
- HMM 支持值不顯示為準確率。兩腳都高於地面只建立 pending 事件；正式 Judge View 維持人工觀察。
- 改地面／區間／目標後撤回地面有效性確認。設定更新只重建尚未確認的自動離地候選，保留人工事件、已確認和已排除的事件。

追拍或轉彎的既有影片，不能只勾選開關就視為校準。若地面線無法維持有效，應保留未知，逐幀人工標 IC／TO。相機運動補償、逐幀地面重建不在本版實作內。

## 1€ 濾波：只疊加顯示

`alpha(fc,dt) = 1 / (1 + 1/(2π fc dt))`

角度單位為 degree、時間為 real second，導數截止頻率 1 Hz，最小截止頻率 1.5 Hz，beta = 0.04。依速度調整截止頻率。輸入或身分缺口會重置濾波器；原始線以淡色保留，深色線是可關閉的趨勢。

原片骨架、角度讀值、窗口最低值和事件時間一律不使用濾波後的值。濾波降低抖動的同時可能延遲，不表示角度更準。

作者方法與調參說明：https://gery.casiez.net/1euro/

## Monte Carlo：假設條件下的角度敏感度

使用髖—膝—踝三點的原片像素座標，對六個座標獨立加入 `Normal(0,σ²)` 誤差，執行 1,024 次。每次重新計算 arccos 膝角，輸出 2.5 與 97.5 百分位數。PRNG 固定種子，讓相同輸入可重現；模擬座標不裁在畫面邊緣，避免人為縮小分布。σ=0 回到原角度。

預設 σ=2 px 是可調的假設（0–20 px），**尚未由宥蓁影片的人工標記校準**。功能預設關閉。介面與匯出標示中央 95%「模擬範圍」，不用「實測信賴區間」。不含認錯人、左右標籤錯誤、二維投影、系統性偏差、不同模型相關誤差或關節點解剖定義差異。

雙模型一致只代表通過交叉檢查，不能拿兩模型差異直接當成真實標準差。此範圍不進入伸膝門檻或訓練處方。

不確定度傳遞方法：https://www.bipm.org/en/doi/10.59161/jcgm101-2008

HMM 步態研究先例（感測器資料，非本網站的競走影片驗證）：https://pubmed.ncbi.nlm.nih.gov/25014927/
